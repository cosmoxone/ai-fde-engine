# AI-FDE Engine 后续规划（Roadmap）

> 文档版本：**v3.0** | 日期：2026-09-16 | 基于：v0.3.0 已发布（488 测试全绿 / 真实 LLM 黄金集 100%）
> 上一版：v2.1（基于 v0.1.0，已过时作废）。历史版本演进见 [CHANGELOG](../CHANGELOG.md)。

---

## 0. 定位（规划的出发点）

**单机开箱即用的开源 FDE 交付引擎**：输入客户文档 → 输出可交付、可验收、可复用的 AI 落地项目。企业级特性（多用户/PG/多租户）在商业轨道（[10-商业计划](10-商业计划.md)），不阻塞开源主线。

## 2. 版本规划

### v0.4.0「知识与本体」——当前迭代（设计见 [13-本体与知识库深化设计](13-本体与知识库深化设计.md) v1.1）

> 架构原则：**知识库为独立模块接入**（协作方开发中，接口规格见 [14-知识库接口规格](14-知识库接口规格.md)）；
> 本项目 = 用户界面 + 前期处理 + 交互处理 + 编排消费。

| 步 | 内容 | 验收 |
| --- | --- | --- |
| **a. 契约与接入层** | `src/knowledge/`：KnowledgeGateway 抽象 + Embedded 参考实现（SQLite FTS5）+ Remote HTTP 网关 + 切块/自动 ingest 管线 + Dashboard 待确认队列 | 契约测试双实现通过；零依赖上传→检索闭环；pending→confirm 交互闭环 |
| **b. 本体抽取** | `src/ontology/`：LLM 增量抽取（实体/关系/规则）+ merge + 本体 API + Mermaid 图 | 多文档实体≥20/关系≥15；增量不重复计数 |
| **c. 整合与回归** | research 经 Gateway RAG 化 + 本体注入 + badcase→CuratedEntry 闭环 + 黄金集回归 | **黄金集 ≥100% 不倒退**；RAG token 成本对比数据 |
| **协作项** | 知识库模块联调（对方按 14 号规格实现后切 `KNOWLEDGE_SERVICE_URL` 实测） | Remote 模式端到端通过 |

### v0.5.x「生态验证」——中期

| 项 | 内容 | 依赖 |

### v1.0.0「稳定承诺」——条件触发（不设时间表）

全部满足才发布 1.0：
- [ ] API 冻结（破坏性变更需 deprecation 周期）
- [ ] 四大卖点各有端到端真实证据（1/2 已达，3/4 待 v0.5）
- [ ] 黄金集扩展至 50 条且 ≥90%
- [ ] 性能/安全验收轻量执行（单机基准文档化）
- [ ] 文档冻结（用户手册/接口规格与实现一致）

### 商业轨道（不占开源版本号）

TE（团队版）/EE 走独立仓库与版本（TE v0.9→v1.0→EE v1.0），复用本仓库扩展点（storage/auth/plugin/template_source/knowledge gateway 均已预留）。详见 [10-商业计划](10-商业计划.md) §5-§8。
