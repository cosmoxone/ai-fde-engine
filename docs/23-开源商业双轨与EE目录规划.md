# 开源商业双轨与 EE 目录规划

> 版本：**v1.2（2026-09-18 v2 修正：TE 单版本订阅阶梯 / EE 数据主权轴）** | 基于：v0.4.0 已发布；[10-商业计划](10-商业计划.md) Open-Core 模式
> 产物：`ee/` 目录（**2026-09-18 起本地开发、gitignore，不入开源仓库**）——本文是双轨总纲
> 一句话：**CE 保持"可独立运营的开源单机内核"；TE 是一个共享 SaaS 版本（Lite/Pro=订阅阶梯，1 用户即 Lite）；EE 是专属部署版本（数据完全独立：本地/云端独立服务器/混合三形态）**

---

## 1. 为什么双轨在工程上是低成本的

v0.4.0 完成两个关键动作：①**契约化外部模块**（知识库 14 号/本体 20 号）——商业版扩展走契约面不动内核；
②**参考实现即规格**——商业版替换实现有现成验收标准。ee/ 只是把这些扩展点的商业实现收拢到独立许可空间。

## 2. 产品矩阵（v1.2 修正）

```
CE（开源单机，自己装）→ TE（一个版本：共享 SaaS，订阅阶梯——1 用户=Lite 档，多人协作=Pro 档，
                        协作方含业务专家/客户用户）
                      → EE（一个版本：专属部署，数据完全独立——
                        本地 / 云端独立服务器 / 混合部署【核心本地×按需云资源】）
```

| | **CE** | **TE**（单版本） | **EE**（单版本） |
| --- | --- | --- | --- |
| 本质 | 开源单机本地部署 | 共享 SaaS（我方托管，多租户隔离） | **专属部署：数据完全独立** |
| 版本/形态 | 一个 | 一个；**Lite/Pro 是订阅档位**（人数×用量），档位切换零迁移 | 一个；部署形态三选：**本地 / 云端独立服务器 / 混合**（本地核心+云资源如 LLM API/云存储/外部 KB） |
| 协作 | 单人 | 多用户（**含业务专家、客户用户等外部协作者**） | 企业多 FDE 多项目 + SSO/RBAC |
| 容量 | 单机 | 订阅档位 | **大容量多项目** + 组织级资产冷启动 + 自助运维工具箱 |
| 商业 | MIT 免费 | 订阅阶梯（1 席起步） | 一口价 + 实施 + 维保 |

**转化漏斗**：CE 免费获客 → TE-Lite 档（1 用户托管）→ TE-Pro 档（团队成长，同版本升档零迁移）→ EE（需数据完全独立时专属安装包整体迁出）。

**EE 核心场景**：交付公司/集成商的专属 AI 交付平台——大容量多项目、企业内部自助式开发（组织资产复用）、**自助维护**（运维工具箱不依赖驻场）、混合部署（核心本地×按需云资源）、对外白标。

## 3. 版本规划（与 CE roadmap 咬合）

| 时间线 | CE（开源主线） | ee/（商业轨） |
| --- | --- | --- |
| v0.4.0 ✅ | 知识与本体（契约×对拍×RAG 终验） | 架构就绪（契约面成型）；ee/ 骨架建立后转本地开发 |
| v0.5 | 生态联动实测、黄金集扩展、稳定性 | **TE v1.0 上线**（单版本：SaaS 平台+多用户协作层+订阅阶梯计量——Lite 档 1 席即可开卖，Pro 档加席位零改动） |
| v0.6+ | 契约 P2 演进、性能验收、模板生态 | **EE v1.0**（专属安装包三形态【本地/云端独立/混合】+ 大容量层 + 运维工具箱 + 混合云路由 + SSO/白标/审计 + TE→EE 迁移工具） |

**红线 5（v1.2 表述）**：TE = CE 同版本功能 + 协作层（差异只在协作与运维面）；Lite/Pro 档位差异是**计量放行，不是功能阉割**。
**红线 6（新增）**：数据主权与反锁定——TE 多租户严格隔离可整体导出；EE 数据不经我方平台；两版均提供完整迁出能力（反锁定是卖点）。

## 4. 四条工程红线（不变，全文见 ee/docs/roadmap-ee.md）

1. 单向依赖（CE 不 import ee；开源 CI 不构建 ee）
2. 契约即扩展点（不 fork 内核网关）
3. 只加不减（商业档不阉割 CE 能力）
4. 开源回馈（通用修复合回主线）

## 5. ee/ 目录与仓库策略（v1.1 修订）

- **ee/ 自 2026-09-18 起 gitignore，本地开发**——商业实现细节不出现在开源仓库（含历史）；开源侧仅保留本文（总纲级规划，无实现细节）
- 结构：`ee/src/{cloud, collaboration, multi_tenant, ops_toolkit, auth, branding}` + `deploy/` + `tests/`
- 构建：EE 镜像 = FROM core 镜像 + ee 层（私有 registry）；TE-Lite 直接编排 CE 镜像

## 6. 对社区的承诺

- CE 功能永不全量商业化；契约文档（14/20 号）永久开源——第三方可自实现替代（Open-Core 信任基础）
- 商业版通用修复 100% 回馈主线
- CE 主线坚持**单机本地部署**形态（云能力只出现在 ee/，CE 代码不含云绑定）
