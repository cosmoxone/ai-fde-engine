# 外部依赖与配置总览

> 版本：**v1.0** | 日期：2026-09-18 | 基于：v0.4.0（契约 14 号 v1.2 × 20 号）
> 用途：一页看全"引擎引用/调用的外部功能"——**必要性分级、默认行为、配置方式**。
> 原则：**Mock 模式零外部依赖可运行**（CI 承诺）；所有外部组件均为可选增强，缺省自动降级并如实标注。

## 1. 总览表（按必要性分级）

| 级别 | 功能域 | 组件/服务 | 默认（不配置时） | 关键配置（环境变量 / .env / Dashboard） |
| --- | --- | --- | --- | --- |
| **核心可选** | LLM | DeepSeek / Qwen / OpenAI 兼容（MiniMax 等）/ Ollama 本地 | **Mock 模式**（流程全通，输出为结构化模拟） | `LLM_PROVIDER` + `DEEPSEEK_API_KEY` / `QWEN_API_KEY`；兼容端点 `LOCAL_MODEL_BASE_URL`+`LOCAL_MODEL_API_KEY`；模型路由 `MODEL_TASK_RESEARCH/CODE/DESIGN/…` |
| **零依赖内置** | 知识库 | **Embedded**（SQLite FTS5+BM25，随主进程）——**CE 唯一推荐形态** | ✅ 默认即用 | 路径 `KNOWLEDGE_DB_PATH`（缺省 `{data_dir}/knowledge.db`）；CE 用户无需任何配置与外部部署 |
| TE/EE 特性 | 知识库（远程） | **kb-os 独立模块**（契约 14 号 v1.2）——**TE 默认形态**（平台项目池） | 不配置=纯 Embedded（CE） | `KNOWLEDGE_SERVICE_URL` / `KNOWLEDGE_SERVICE_TOKEN`；CE 主线不宣传此路径（对接编排属 TE/EE 场景，ee 层配置） |

| 可选增强 | 文档解析 | Docling（高质量 PDF/Office） / Marker v2（GPU 快） | 内置基础解析（core 镜像） | `DOC_PARSER_PROVIDER=docling|marker|hybrid|mock`（full 依赖集） |

| 可选增强 | 代码生成 | Aider / OpenHands / OpenCode（night-factory 工单执行） | Mock 工单导出 | `CODE_GEN_PROVIDER`；工单目标仓库 `NIGHT_FACTORY_TARGET_REPO` |
| 可选增强 | 测试执行 | 外部 RPA 项目（webhook） | Mock 执行器 | RPA webhook 配置（`src/integrations/rpa_runner.py`，环境注入） |
| 可选增强 | 评测 | DeepEval | Mock 评分 | `EVALUATION_PROVIDER=deepeval|mock` |
| 可选增强 | 可观测 | Langfuse | 关闭 | `OBSERVABILITY_PROVIDER=langfuse` + `LANGFUSE_HOST` |

| 基础设施（全量编排用） | 存储/缓存 | PostgreSQL / Redis / MinIO | SQLite 单文件（core） | `STORAGE_PROVIDER`、`POSTGRES_*`、`REDIS_*`（仅 docker-compose.full） |

## 2. 三种部署形态对应的外部依赖

| 形态 | 外部依赖 | 说明 |
| --- | --- | --- |
| **core 镜像（推荐起步）** | 仅 LLM Key（可选） | Mock 模式开箱即用；知识库/本体 Embedded；`ghcr.io/cosmoxone/ai-fde-engine:v0.4.0` |
| core + kb-os | + kb-os 实例 + scoped key | 团队共享知识库 / 独立运维；契约对拍 13/13 已验证 |
| full 全量编排 | + Qdrant/PG/Redis/MinIO/Docling/… | v0.2 实验路径（[04 号](04-部署方案.md) 附录），知识库部分已被契约路线取代 |

## 3. 配置方式（三种等价）

1. **环境变量 / `.env`**（部署首选）：全部字段见 `src/config.py`（pydantic-settings，大小写不敏感）
2. **Dashboard 热配置**（LLM）：`POST /api/v1/settings/llm`（热生效 + 持久化到 `data/llm_settings.json`）
3. **代码内工厂**：`get_knowledge_gateway()` / `get_ontology_gateway()` 按 URL 配置自动选 Embedded/Remote/Fallback——业务代码无感

## 4. 判缺省行为速查（"不配会怎样"）

| 不配置 | 行为 |
| --- | --- |
| LLM Key | Mock 模式：全流程可跑通（演示/测试），输出非真实模型生成 |
| KNOWLEDGE_SERVICE_URL | 纯 Embedded 知识库（单机完整功能） |
| ONTOLOGY_SERVICE_URL | 纯 Embedded 本体 |
| mem0 包未装 | 本地记忆降级（日志提示），不影响主流程 |
| Docling 未装 | 内置基础解析（Markdown/文本/常见格式） |
| kb-os 不可达（已配置） | Fallback：自动降级 Embedded + `degraded_since` 标记；`retry_remote()` 恢复 |
