# 智能制造质量管理系统业务手册（节选）

> 本文档为模拟客户业务文档示例，用于演示 AI-FDE Engine 的调研分析流程。

## 1. 公司简介

华宇精密制造有限公司是一家专注于精密零部件加工的制造企业，主要服务汽车零部件和消费电子两大行业客户。公司现有员工 850 人，其中质检人员 45 人，年产值约 6.2 亿元。

## 2. 质量管理现状

### 2.1 质检流程

目前公司的质量检验流程如下：

1. **来料检验（IQC）**：原材料到货后，质检员根据《来料检验标准》进行抽检，重点检查尺寸公差、表面光洁度和材质证明文件。每批次检验耗时约 40 分钟。
2. **过程检验（IPQC）**：生产过程中每 2 小时巡检一次，记录关键工序参数。异常时填写《质量异常单》并通知产线主管。
3. **成品检验（OQC）**：成品入库前全检或抽检，依据客户验收标准执行。

### 2.2 主要痛点

- **检验标准分散**：检验标准分散在 200 多份纸质和电子文档中，新员工培训周期长达 3 个月
- **查询效率低**：遇到不常见的检验场景，质检员平均需要 20 分钟才能找到对应标准
- **经验难沉淀**：资深质检员的判定经验存在个人头脑中，人员流失导致经验流失
- **异常处理慢**：质量异常单流转依赖纸质签核，平均处理周期 2.5 天

### 2.3 现有数据资产

| 数据系统 | 数据内容 | 数据量 | 更新频率 |
| ------- | ------- | ------ | -------- |
| ERP 系统 | 供应商、物料、批次信息 | 约 12 万条 | 实时 |
| MES 系统 | 工序参数、生产报工 | 日均 3 千条 | 实时 |
| QMS 系统 | 检验记录、异常单 | 累计 45 万条 | 实时 |
| 文档服务器 | 检验标准、作业指导书 | 约 2000 份 | 月度 |

## 3. 期望目标

1. 构建智能质量知识库：质检员通过自然语言提问，10 秒内获得检验标准依据
2. 检验报告自动生成：拍照或选择检验项后自动生成规范检验报告
3. 质量异常智能归因：基于历史数据辅助定位异常根因
4. 交付周期预期：希望 2 周内上线第一个可用版本

## 4. 验收标准（客户初步要求）

- 检验标准问答准确率 ≥ 90%
- 高频问题（Top 100）响应时间 ≤ 3 秒
- 知识库覆盖全部 A 类物料的检验标准（约 300 份文档）
- 质检员满意度 ≥ 4.0 / 5.0
