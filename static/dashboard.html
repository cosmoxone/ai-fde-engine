API 接入文档

两种使用模式：交互式调用 / 后台异步流水线
模式一：交互式调用（同步/异步API）

前端工具、IDE插件、聊天界面直接调用API，实时获取结果。

# 创建项目
POST /api/v1/projects
{"name":"智能客服项目","industry":"电商"}

# 触发调研分析（异步）
POST /api/v1/projects/{id}/research/run
# 返回 task_id，轮询 GET /api/v1/tasks/{task_id}

# 触发方案设计（异步）
POST /api/v1/projects/{id}/design/run

# 触发开发交付（异步）
POST /api/v1/projects/{id}/delivery/run

# 自助交付（同步）
POST /api/v1/projects/{id}/self-service/opportunities
POST /api/v1/projects/{id}/self-service/requirements
POST /api/v1/projects/{id}/self-service/solution
POST /api/v1/projects/{id}/self-service/prototype
模式二：后台异步流水线

提交需求后，Agent在后台自动完成全流程，完成后通知人工审核。

# 1. 提交项目需求（交互完成）
POST /api/v1/projects
POST /api/v1/projects/{id}/documents (上传资料)

# 2. 后台自动执行（无需人工干预）
ResearchAgent → 调研分析
DesignAgent   → 方案设计
DeliveryAgent → 代码生成
QualityGate   → 质量门禁
NightlyPipeline → 夜间迭代

# 3. 完成后自动入审核队列
GET /api/v1/self-service/review/pending

# 4. 人工审核确认
POST /api/v1/self-service/review/{id}/action
{"action":"approve","comment":"通过"}

# 5. 审核通过 → 通知客户 / 部署上线
